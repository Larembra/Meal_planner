# Meal Planner

Веб-приложение для персонального планирования питания. Пользователь настраивает цель, тип питания, аллергены и число приёмов пищи, затем получает рацион на выбранное число дней. Генератор подбирает блюда из базы и составляет план через OpenRouter; сохранённый рацион можно просматривать по дням.

## Возможности

- Регистрация, вход и профиль пользователя.
- Генерация рациона на 3, 4 или 5 приёмов пищи с учётом предпочтений и ограничений.
- Просмотр сохранённого рациона и переключение между днями.
- Каталог блюд и рецептов, список покупок и трекинг питания.
- FastAPI-бэкенд, React-фронтенд и PostgreSQL с pgvector.

## Запуск

Инструкции по запуску на Windows и macOS, настройке `backend/.env` и подготовке базы находятся в [backend/README.md](backend/README.md).
